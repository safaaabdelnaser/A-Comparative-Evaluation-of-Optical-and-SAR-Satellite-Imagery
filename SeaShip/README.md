# 🌊 SeaShip Dataset

## 📘 Description
The **SeaShip Dataset** is a large-scale **optical image dataset** created for ship detection and classification tasks in computer vision.  
It contains visible-light (RGB) images of ships captured under various lighting and sea conditions, providing a comprehensive benchmark for evaluating detection models in **optical maritime environments**.

## 📊 Dataset Details
| Property | Description |
|-----------|-------------|
| **Type** | Optical RGB images |
| **Number of Images** | 31,455 images |
| **Resolution** | 1920 × 1080 pixels (average) |
| **Classes** | 6 ship types — Cargo, Passenger, Fishing, Warship, Tug, Others |
| **Format** | `.jpg` images with `.xml` or `.txt` annotations |
| **Purpose** | Ship detection and classification in optical domain |
