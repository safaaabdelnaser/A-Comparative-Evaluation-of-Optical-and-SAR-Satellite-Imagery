# 🚢 Open SAR Ship Dataset

## 📘 Description
The **Open SAR Ship Dataset** (OpenSARShip) is a publicly available SAR (Synthetic Aperture Radar) dataset designed for **ship detection and classification** tasks.  
It provides high-resolution radar images collected from **Sentinel-1 satellites**, covering diverse sea areas and environmental conditions.  

This dataset enables researchers to develop and evaluate deep learning algorithms for **maritime surveillance**, **ship recognition**, and **object detection in SAR imagery**.

## 📊 Dataset Details
| Property | Description |
|-----------|-------------|
| **Type** | Synthetic Aperture Radar (SAR) images |
| **Sensor Source** | Sentinel-1 satellite |
| **Number of Images** | 11,346 patches |
| **Resolution** | 256 × 256 pixels |
| **Classes** | Ship / Non-ship |
| **Format** | `.jpg` or `.png` images with annotation `.txt` (YOLO format) |
| **Purpose** | Training and evaluation of ship detection algorithms |
