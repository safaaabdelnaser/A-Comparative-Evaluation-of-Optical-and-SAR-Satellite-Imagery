# 🛰️ FUSAR Dataset Overview

## 📘 Description
The **FUSAR Dataset** is a Synthetic Aperture Radar (SAR) ship detection dataset designed for maritime target recognition and segmentation.  
It contains radar images captured under various sea conditions and backgrounds, enabling the evaluation of deep learning models for ship detection, classification, and recognition in complex maritime scenes.
## 📊 Dataset Details
| Property | Description |
|-----------|-------------|
| **Type** | Synthetic Aperture Radar (SAR) images |
| **Number of Images** | 10,000+ |
| **Resolution** | 512 × 512 pixels |
| **Classes** | Ship / Background |
| **Format** | `.jpg` or `.tif` images + YOLO format labels |
| **Use Case** | Ship detection and classification under various environmental conditions |
