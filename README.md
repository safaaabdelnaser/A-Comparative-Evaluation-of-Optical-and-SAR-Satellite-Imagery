# A Comparative Evaluation of Optical and SAR Satellite Imagery

This repository contains multiple datasets and code implementations used for ship detection experiments in both Optical and SAR (Synthetic Aperture Radar) satellite imagery.  
The goal is to perform a comparative evaluation of different datasets and methods for maritime surveillance and ship detection tasks.

## 🧠 Description

Each subfolder contains:
- The dataset used for training and evaluation.
- The implemented model code (YOLO-based variations, CNN, or hybrid architectures).
- Visual results and performance metrics (Precision, Recall, mAP, etc.).

## ⚙️ Technologies

- **Python 3.10**
- **PyTorch**
- **YOLOv8 / YOLOv10**
- **OpenCV**
- **Matplotlib**
