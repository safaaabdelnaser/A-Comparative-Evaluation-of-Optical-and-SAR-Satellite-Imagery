# 🚢 ShipRSImageNet Dataset

## 📘 Description
The **ShipRSImageNet Dataset** is a large-scale **optical remote sensing** dataset created for **ship detection and recognition** tasks.  
It contains high-resolution RGB satellite images collected from multiple sensors, covering diverse ocean regions, ship sizes, and environmental conditions.  
This dataset is widely used for evaluating the **generalization ability** of deep learning models in optical maritime imagery.

## 📊 Dataset Details
| Property | Description |
|-----------|-------------|
| **Type** | Optical RGB satellite images |
| **Number of Images** | 50,000+ |
| **Resolution** | 256 × 256 to 1024 × 1024 pixels |
| **Classes** | Ship / Background |
| **Format** | `.jpg` images with YOLO `.txt` labels |
| **Purpose** | Training and evaluating deep learning models for ship detection in optical imagery |
